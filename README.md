# Bsun QR Code Reader

A browser-based QR code reader developed using HTML, CSS and JavaScript.

Bsun QR Code Reader allows users to scan QR codes using their device's camera or upload an existing QR-code image.

**Developer:** Bisan Subba

## 🌐 Live Application

https://bsun7131.github.io/Bsun-QR-Code-Reader/

## ✨ Features

* 📷 Scan QR codes using a camera.
* 🖼️ Read QR codes from uploaded images.
* 📝 Display decoded text and website URLs.
* 📋 Copy scanned information to the clipboard.
* 🌐 Open recognised HTTP and HTTPS website links.
* 🗑️ Clear scanning results.
* 📱 Responsive interface for desktop and mobile browsers.
* 🔐 Local QR-code processing without an external decoding service.
